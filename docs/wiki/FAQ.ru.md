# FAQ

[English](FAQ.md) · **Русский** · [Oʻzbekcha](FAQ.uz.md) · [简体中文](FAQ.zh-CN.md)

**С какими агентами это работает?**
С любым агентом, который читает Agent Skills (папки с `SKILL.md`): Claude Code, Codex,
Cursor, Gemini CLI, GitHub Copilot и другими. Для остальных укажите на скиллы в
`AGENTS.md`. См. [Установка](Install.ru.md).

**Это официальный проект?**
Нет. Проект не связан ни с одним провайдером. Заметки сделаны по публичной документации
для разработчиков, и главным источником остаётся она.

**Можно использовать в коммерческом проекте?**
Да, по лицензии MIT.

**Нужен ли агенту интернет?**
Нет. Заметки о контрактах, схемы, данные песочницы и инструменты лежат в репозитории.
Интернет нужен только для `scripts/sync`, которым мейнтейнеры сверяются с upstream.

**Почему агент не называет комиссию?**
Ставки комиссии, доли выплат и сроки расчётов зависят от договора каждого мерчанта. Число
из скилла было бы неверным для большинства мерчантов, поэтому агент отсылает к вашему
договору. Поля комиссий, которые возвращает API, он объясняет как обычно.

**Почему агент предупреждает о том, о чём я не спрашивал?**
Потому что это ошибки, которые потом стоят денег: чек возврата после фискального
дедлайна, транзакция, подтверждённая после истечения срока, отмена, которая не возвращает
деньги. Предупреждения короткие и имеют стабильные ID. См. [Lifecycle](Lifecycle.ru.md).

**Где тестовые карты?**
В `skills/<provider>/references/sandbox/README.md`, ровно в том виде, в каком их публикует
каждый вендор. Paynet их не публикует; скилл так и говорит, а не придумывает карту.

**Безопасны ли мои секреты с инструментами?**
Инструменты читают секреты только из переменных окружения, печатают их как `<SECRET>` и
ничего не отправляют в сеть. Никогда не вставляйте боевые ключи в чат с агентом.

**Насколько свежая информация?**
У каждой справки есть URL источника и дата загрузки. Еженедельный workflow сверяет
источники с upstream и открывает PR, когда что-то меняется. Проверить самостоятельно можно
через `scripts/sync --check`.

**Можно спрашивать на русском, узбекском или китайском?**
Да. Агент отвечает на вашем языке, а имена API оставляет как есть.

**Я нашёл ошибку. Что делать?**
Откройте issue со ссылкой на страницу вендора, где указан правильный факт, или пришлите PR.
См. [Как помочь](Contributing.ru.md).
