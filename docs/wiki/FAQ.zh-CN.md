# 常见问题

[English](FAQ.md) · [Русский](FAQ.ru.md) · [Oʻzbekcha](FAQ.uz.md) · **简体中文**

**支持哪些智能体？**
任何能读取 Agent Skills（`SKILL.md` 文件夹）的智能体：Claude Code、Codex、Cursor、Gemini CLI、GitHub Copilot 等。对于其他智能体，在 `AGENTS.md` 中指向这些技能即可。参见[安装](Install.zh-CN.md)。

**这是官方项目吗？**
不是。本项目与任何服务商均无关联。这些笔记整理自公开的开发者文档，一切以该文档为准。

**可以用在商业项目中吗？**
可以，遵循 MIT 许可证。

**智能体需要联网吗？**
不需要。接口契约笔记、Schema、沙箱数据和工具都在仓库里。只有 `scripts/sync` 需要联网，维护者用它与上游进行比对。

**为什么智能体不肯告诉我手续费？**
手续费率、分成比例和结算天数因商户合同而异。技能里给出的数字对大多数商户都会是错的，所以它会让你去查自己的协议。API 返回的费用字段会正常解释。

**为什么智能体会就我没问的事情发出警告？**
因为这些错误日后会造成金钱损失：过了税务登记截止时间才发送的退款小票，已经过期后才确认的交易，不会退回资金的取消操作。这些警告都很简短，并有稳定的 ID。参见[生命周期](Lifecycle.zh-CN.md)。

**测试卡在哪里？**
在 `skills/<provider>/references/sandbox/README.md` 中，与各服务商公布的完全一致。Paynet 没有公布测试卡，Octo 没有公布测试卡和 OTP（只有生产主机上的 `test` 标志），Oson 和 Kapitalbank 既没有公布测试主机，也没有公布任何测试数据。各技能都会如实说明，而不是编造一张。

**用这些工具，我的密钥安全吗？**
工具只从环境变量读取密钥，输出时显示为 `<SECRET>`，并且不通过网络发送任何内容。绝不要把生产环境的密钥粘贴到与智能体的对话中。

**信息有多新？**
每条参考资料都注明了来源 URL 和抓取日期。每周有一个工作流把这些来源与上游比对，有变化时开一个 PR。你也可以运行 `scripts/sync --check` 自行检查。

**可以用俄语、乌兹别克语或中文提问吗？**
可以。智能体会用你的语言回答，API 名称保持原样。

**我发现了错误，怎么办？**
开一个 issue，附上能证明正确事实的服务商页面，或者直接发 PR。参见[参与贡献](Contributing.zh-CN.md)。
