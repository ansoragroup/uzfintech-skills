The answer sees that the code has 16 digits because it is sent as a number and lost its
leading zero, says the IKPU must be the 17-digit value sent as a string (for example
`"06401004002000000"`, to be confirmed on tasnif.soliq.uz), and says `package_code` is
required and must be taken, as a string, from the same code's card on Tasnif. It does not
invent a package code, does not present an unconfirmed code as certainly correct, and gives
no advice on which VAT rate applies.
