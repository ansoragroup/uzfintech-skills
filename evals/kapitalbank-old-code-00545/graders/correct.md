The answer says `00545` is an old purpose code that banks refuse from 26.05.2026, and that
it splits into several new codes by material, so aluminium goods take `00076` (the table's
note "изготовленные из аллюминия"). It proposes a `purpose` text that contains the code, the
goods, the contract number 100001 and its date 03.11.2026, and the payment type (full
payment). Saying these rules apply in every Uzbek bank passes. Picking a different code for
aluminium goods, keeping `00545`, or leaving the contract date or the goods out of the text
fails. Inventing an API host or claiming the text layout is prescribed by the CBU fails.
